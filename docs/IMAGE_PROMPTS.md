# Fondos de referencia

Se usó la herramienta integrada de generación de imágenes (sin CLI ni clave de API).

Archivos finales de la aplicación:
- `public/assets/hero-interstellar-reference.webp`
- `public/assets/auth-reference.webp`

Se conservaron las imágenes originales de generación en la carpeta de imágenes de Codex. Los WebP de la app son copias optimizadas sin cambiar su composición. Estos fondos son recreaciones generadas a partir de las referencias del usuario, no fotogramas oficiales de las películas.

## Hero de Inicio — prompt

Use case: precise-object-edit. Asset type: clean cinematic website hero background, wide 16:9, 1920x1080 feel. Input image is the supplied UI collage. Extract and faithfully reconstruct ONLY the panoramic illustration in the UPPER LEFT desktop screen, the hero behind INTERSTELLAR: a single astronaut viewed from behind in a white-gray space suit, standing amid dark cloud tops at the right two-thirds, facing a vast glowing golden black-hole ring arcing through the upper right sky, blue-black star field, moody realistic cinematic lighting. Match that scene's composition, colors, astronaut scale and luminous ring as closely as possible. Reconstruct all background obscured by interface text. The left 45 percent must remain very dark blue-black with subtle clouds and stars, usable as text negative space. No water scene, no frontal astronaut face, no mountains, no people other than this single astronaut. Remove ALL UI, all typography, all posters, all sidebar, all player, all borders, all buttons. Output ONE single continuous full-bleed landscape background photograph/illustration filling the image; absolutely no collage, phone frames, text, logos or interface controls. The provided image is reference/edit target for the scene, preserve that hero scene and extend it naturally to a clean 16:9 image.

Referencia: Panel de streaming cinematográfico Liner-1.png.

## Acceso a cuentas — prompt

Use case: precise-object-edit. Asset type: clean background for AFTERSCENE login web page, single wide 16:9 cinematic image. The attached image is a UI collage. Faithfully reconstruct only the cinematic artwork behind the TOP LEFT login screen and the lower right branding panel: a lone young traveler with dark brown shoulder-length hair seen from behind, wearing a dark jacket and backpack, seated on rough dark rocky overlook in the lower-left/center foreground, contemplating a vast futuristic city below. A gigantic luminous golden celestial ring curves through a cloudy sunset sky, warm amber horizon and blue-black storm clouds. Match the reference artwork's actual colors, cinematic realism, mood and composition very closely. Frame the traveler in the LEFT 40 percent and keep the RIGHT 40 percent as a dark atmospheric distant city/cloud field usable behind a form. Remove all UI panels, all lettering, all phones, all borders, all logos, all controls and all text. Output one continuous full bleed photographic cinematic landscape only, no collage, no illustration of interface. Preserve the dark rocks, warm city sunset and immense glowing ring, with the traveler looking away from the viewer.

Referencia: Concepto UI cinematográfico de AFTERSCENE.png.
